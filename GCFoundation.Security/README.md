# GCFoundation.Security

`GCFoundation.Security` provides security-related middleware, configuration, and helpers for GCFoundation-based ASP.NET applications.

It is designed to work alongside the Government of Canada Design System (GCDS) and the other GCFoundation packages.

## Usage

Install the NuGet package:

```powershell
dotnet add package GCFoundation.Security
```

For full documentation and examples, see the main GCFoundation README in the repository.
